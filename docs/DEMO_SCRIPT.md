# Demo video script (Step 12): 2-3 minutes

Record the **deployed** app with real providers (OBS, Loom or the built-in screen recorder). Use a clear brief, e.g. *EcoSip Bottle*.

| Time | Show | Say |
|---|---|---|
| 0:00 | Landing page | "This is an AI Marketing Content Generator: one brief in, a full campaign out." |
| 0:10 | Fill the brief (product, description, audience, platform, objective, tone, language) | "I give it the product, audience, goal, platform and tone." |
| 0:30 | Submit; progress steps | "An agent plans the campaign, shows each step and can pause for my approval." |
| 0:50 | Strategy | "Structured strategy: idea, audience, selling points, tone, CTA, KPIs, validated against a schema." |
| 1:10 | Content studio | "Platform-specific copy, several variations, regenerate one or pick a favourite." |
| 1:30 | Creatives | "Image prompts are written by the LLM and rendered by the image model; I can upload my product photo or ask for a revision." |
| 1:55 | Submit the same brief again | "Same brief: instant, no new API call." |
| 2:05 | Error handling (wrong key or burst of requests) | "Clear messages, rate limiting and other assets keep going." |
| 2:20 | `/api/metrics` or logs, architecture diagram | "Monitoring of AI calls, structured logs, Dockerised and deployed." |
| 2:40 | Export approved assets | "Approve and export the finished campaign." |
